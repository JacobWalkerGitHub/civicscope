# Security review: OWASP Top 10 (2021)

Reviewed 2026-11-03 against the code on `main` plus this launch-hardening change, before the
first production deploy. A checklist review, not a penetration test. Repeat it before launch
and after any change to sign-in, permissions, uploads or outbound fetching.

**Result: no open high issues.** Two medium issues were found and fixed in this change. One
high issue (API keys in the public repository) needs the owner to replace the keys; the files
no longer contain them.

## Known, accepted for launch

- **CSP allows inline scripts** (low). Moving to per-request nonces makes every page dynamic
  and needs middleware; React's escaping is the main defense against XSS here. Revisit if the
  site ever renders user-supplied HTML.
- **Search is not rate-limited in the app** (low). The WAF limits it to 600 requests per IP
  per 5 minutes.
- **The NAT gateway is in one zone** (availability, not security). If that zone fails, ingests
  pause; the site keeps running.
